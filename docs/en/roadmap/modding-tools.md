# Modding tools

*Español: [../../roadmap/herramientas-modding.md](../../roadmap/herramientas-modding.md)*

**Status:** ongoing · [Roadmap](../../../ROADMAP.md)

## Why
Modding is what keeps a game like this alive: rosters, textures, stadiums, seasons. The tools should make that easy without touching the game files.

## Where we are
- **Texture Studio:** browse, export and import every texture; AI upscaling; Dolphin packs.
- **Season Editor:** real schedules 2002–2026, start year, DH, 15/15 leagues.
- **Rosters:** PowerUp+ adapted to 2008, imported into every mode, MLB Life included.
- **Stadiums:** Blender add-on that builds a stadium from scratch and previews it in the game.

## Next
- Custom stadiums in Season mode and MLB Life (today only Exhibition).
- The game's text format (PCD) decoded, so names and texts can be modded.
- Models and the textures whose palette lives in another pack.
- A single place in the launcher to see, enable and order every mod.
